# Ecommerce_sales_analysis-

## E-commerce Sales Analysis Using SQL

## Project Overview
This is my first data analytics project, where I explored and analyzed e-commerce sales data using SQL. The project focuses on identifying data quality issues, cleaning the dataset, and extracting meaningful business insights.

## Objectives
- Inspect and understand the raw sales data.
- Identify and handle data quality issues.
- Prepare a cleaned dataset for analysis.
- Analyze sales performance and customer purchasing patterns.
- Answer business questions using SQL queries.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Project Files
- `messy_ecommerce_sales_data.csv` – Original dataset.
- `cleaned_ecommerce_sales.csv` – Cleaned dataset.
- `business_analysis_of_ecommerce_sales.sql` – SQL queries used for business analysis.

## Analysis Performed
- Data exploration and inspection.
- Data cleaning and standardization.
- Sales analysis by product category.
- Gender-based sales analysis.
- Business question analysis to identify useful insights.

## Key Learnings
Through this project, I gained practical experience in SQL, data inspection, data cleaning, aggregation, and analyzing sales data to answer business questions.

## Conclusion
This project helped me apply my SQL knowledge to a practical dataset and develop my data analytics skills. It is an important first step in my journey toward becoming a data analyst.
